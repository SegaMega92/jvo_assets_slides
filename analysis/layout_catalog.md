# Каталог лейаутов JVO

Анализ 86 слайдов из 3 файлов → 45 структурных кластеров → 11 канонических лейаутов.

Все размеры в **% от слайда** (для 960×540 одинаково с 1920×1080).

---

## Общая система (присутствует на ВСЕХ слайдах)

```
┌─────────────────────────────────────────────────────────┐
│ [TITLE 2%, 3.5%, w:70%]              [LOGO 93.7%, 3.5%] │  ← title bar
│                                       4.3% × 7.7%       │
│                                                         │
│              [ BODY 2%, 16%, w:96% ]                    │
│              [   разные паттерны     ]                  │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

**Фиксированные элементы (slide chrome):**
- `Logo`: `right: 6.3%, top: 3.5%, size: ~4.3% × 7.7%` — всегда правый верх
- `Title`: `left: 2%, top: 3.5%, width: ~70%, font: 28pt Unbounded SemiBold`

**Зоны слайда:**
- Title bar: `top: 0-12%`
- Body: `top: 12-95%`, отступ 2% слева/справа

## 1. BigStatement — крупное утверждение

**Когда:** одна важная фраза/цитата/тезис на весь слайд.
**Кластер 1, 6 слайдов** (КП Дживио #11–12, enterprise #23–24, 30).

```
┌─────────────────────────────────────────────────────────┐
│                                              [LOGO]     │
│      [иконка/иллюстрация ~33%, 15%]                     │
│      [BIG TEXT, 28pt, ~70% wide ]                       │
│      «это больше, чем все существующие платформы…»      │
│      [подложка/линия/декор]                             │
└─────────────────────────────────────────────────────────┘
```

**Слоты:**
- `illustration` (optional) — иллюстрация над текстом
- `statement` — крупный текст (1–2 строки)
- `decoration` (optional) — нижняя графика

## 2. TitleAndCardGrid — заголовок + сетка карточек

**Когда:** показываем 3–4 равных блока (преимущества, шаги, опции).
**Кластеры 6, 11, 12, ~10 слайдов.**

```
┌─────────────────────────────────────────────────────────┐
│ [TITLE]                                       [LOGO]    │
│ [subtitle / lead, 12pt]                                 │
│                                                         │
│ ┌──────────┐ ┌──────────┐ ┌──────────┐  ┌──────────┐    │
│ │ icon     │ │ icon     │ │ icon     │  │ icon     │    │
│ │ heading  │ │ heading  │ │ heading  │  │ heading  │    │
│ │ body     │ │ body     │ │ body     │  │ body     │    │
│ └──────────┘ └──────────┘ └──────────┘  └──────────┘    │
└─────────────────────────────────────────────────────────┘
```

**Слоты:**
- `title` (28pt)
- `lead` (12pt) — опциональный подзаголовок
- `cards[]` — 2/3/4 карточек, каждая: `{ icon, heading, body }`

**Геометрия карточек:** в данных видно `~31% × 53%` для 3 карточек, `~24% × 33%` для 4.

## 3. ComparisonTwoColumns — «Раньше / Сейчас», «Мы / Вы»

**Когда:** сравнение двух сценариев side-by-side.
**Кластер 9, 12 — 4 слайда.**

```
┌─────────────────────────────────────────────────────────┐
│ [TITLE «Рынок изменился»]                     [LOGO]    │
│ [lead]                                                  │
│                                                         │
│ ┌──────────────────────┐  ┌──────────────────────┐      │
│ │ Раньше               │  │ Сейчас               │      │
│ │ • bullet             │  │ • bullet             │      │
│ │ • bullet             │  │ • bullet             │      │
│ └──────────────────────┘  ┌──────────────────────┘      │
│       [↑ central arrows/connector, optional]            │
└─────────────────────────────────────────────────────────┘
```

**Слоты:**
- `title`, `lead`
- `leftColumn: { heading, items[] }`
- `rightColumn: { heading, items[] }`
- `connector` (optional) — стрелки между колонками

## 5. ClientCase — кейс клиента

**Когда:** результаты работы с клиентом (логотип + цифры + продукт).
**Кластер 2, 6 слайдов.**

```
┌─────────────────────────────────────────────────────────┐
│ [CLIENT LOGO «Laretto»]   [TAG «Прирост 26%»]  [LOGO]   │
│ ┌──────────────────────────────────────────────────┐    │
│ │ [card with pink/light bg, 96% wide, 80% tall]    │    │
│ │  ┌─────────┐  ┌───────────┐  ┌─────────────┐     │    │
│ │  │ product │  │ stats     │  │ key metric  │     │    │
│ │  │ photo   │  │ table     │  │ blocks      │     │    │
│ │  └─────────┘  └───────────┘  └─────────────┘     │    │
│ │                            [client photo + caption]│   │
│ └──────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────┘
```

**Слоты:**
- `clientName` (28pt)
- `resultTag` (12pt в pill) — краткий результат
- `productImage`
- `metricsTable` — таблица с цифрами
- `metricsHighlights[]` — выделенные метрики
- `clientPhoto` (optional) — фото клиента
- `clientCaption` (optional)

## 6. PricingTariffs — тарифные таблицы

**Когда:** сравнение тарифов / прайс-лист.
**Кластер 3, 6 слайдов.**

```
┌─────────────────────────────────────────────────────────┐
│ [LOGO icon]                                   [LOGO]    │
│ «Дживио Агент»                                          │
│  «Оплата за действие»                                   │
│ ┌──────────┐ ┌──────────┐ ┌──────────┐                  │
│ │ tariff   │ │ tariff   │ │ tariff   │                  │
│ │ table 1  │ │ table 2  │ │ table 3  │                  │
│ │ ~33%×58% │ │ ~33%×58% │ │ ~33%×58% │                  │
│ └──────────┘ └──────────┘ └──────────┘                  │
│ ─── (line divider) ───                                  │
│ [Спец. предложение | Бонус блок]                        │
│ [Выбирают крупнейшие бренды]                            │
└─────────────────────────────────────────────────────────┘
```

**Слоты:**
- `productName` (вместо title)
- `lead`
- `tariffs[]` — 2 или 3 таблицы
- `specialOffer` (optional) — подвал с акцией
- `socialProof` (optional) — «выбирают бренды X»

**Когда:** список из 10+ небольших элементов в матрицу.
**Кластер 4, 4 слайда.**

```
┌─────────────────────────────────────────────────────────┐
│ [TITLE «Чтобы продавать больше...»]           [LOGO]    │
│ [lead «Это лишь часть параметров»]                      │
│                                                         │
│  [tag] [tag]    [tag]         [tag]                     │
│  [tag] [tag]       [tag] [tag]                          │
│  [tag]    [tag] [tag]    [tag]                          │
│                                                         │
│  ↑ небольшие pill-карточки, ~6.7% high, ширина варьир.  │

```

**Слоты:**
- `title`, `lead`
- `tags[]` — массив строк, рендерим как pills с автопереносом

## Универсальные правила

**Logo** всегда в правом верхнем углу: `right: 38px, top: 19px` (для 960×540) = `right: 76px, top: 38px` (для 1920×1080).

**Padding слайда**: 2% слева/справа = ~19px (960) или ~38px (1920).

**Title bar height**: ~25% сверху (от `top: 3.5%` до `top: 28%`) — содержит title + lead.

**Цвета**:
- Светлые слайды: фон `#FFFFFF` или `#FBFBFB`, текст `#410031` / `#15181F`
- Темные/акцентные: фон `#410031`, `#1F2A09`, `#34034C` + текст `#FFFFFF` или акцент

**Шрифты**:
- Title/headings: `Unbounded SemiBold/Medium`
- Body/UI: `Manrope Medium/SemiBold`
